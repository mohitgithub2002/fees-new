# Fees: School Fee Recovery System

An app for school owners and principals in India to **recover more of their school fees**. It helps them:

- find the families who **can pay but aren't paying**
- understand each family's **payment habits**
- give staff the **full picture before every call**
- **predict** how much money will come in
- spot **missing money**

Current stage: **planning**. There is no code yet.
